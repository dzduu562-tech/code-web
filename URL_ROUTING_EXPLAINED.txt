   public/auth/register.php  ← KHÔNG TỒN TẠI!


✅ THỰC TẾ:
═══════════════════════════════════════════════════════════════════════
URL: http://localhost/elearning/public/auth/register

ĐƯỢC XỬ LÝ BỞI:
   1. public/index.php           ← Entry point
   2. app/core/App.php           ← Router
   3. app/controllers/Auth.php   ← Controller
   4. app/views/auth/register.php ← View


FLOW CHI TIẾT:
═══════════════════════════════════════════════════════════════════════

[1] Browser gửi request:
    → http://localhost/elearning/public/auth/register

[2] Apache nhận request, đọc public/.htaccess:
    RewriteRule ^(.*)$ index.php?url=$1 [QSA,L]
    
    Chuyển thành:
    → http://localhost/elearning/public/index.php?url=auth/register

[3] File public/index.php chạy:
    ```php
    session_start();
    define('ROOT', dirname(__DIR__));
    define('APP', ROOT . '/app');
    
    require_once APP . '/helpers/functions.php';
    $app = new App();  // ← Khởi động router
    ```

[4] Class App (Router) parse URL:
    ```php
    // app/core/App.php
    $url = explode('/', 'auth/register');
    // $url = ['auth', 'register']
    
    $controller = 'Auth';      // ← Lấy từ $url[0]
    $method = 'register';      // ← Lấy từ $url[1]
    ```

[5] Load Controller:
    ```php
    require_once APP . '/controllers/Auth.php';
    $controller = new Auth();
    ```

[6] Gọi method:
    ```php
    $controller->register();  // ← Gọi method register()
    ```

[7] Trong Auth::register():
    ```php
    public function register() {
        // Xử lý logic...
        
        // Load view
        $this->view('auth/register', $data);
    }
    ```

[8] Method view() include file:
    ```php
    // app/core/Controller.php
    public function view($view, $data = []) {
        extract($data);
        require_once APP . '/views/' . $view . '.php';
        // → require_once 'app/views/auth/register.php'
    }
    ```

[9] File app/views/auth/register.php render HTML
    → Gửi về browser

# Hướng dẫn chạy dự án E-Learning

Mã nguồn được đặt trong thư mục `elearning`. Chép cả thư mục này vào `htdocs` của XAMPP để chạy.

- Đường dẫn: `http://localhost/elearning/public/index.php?route=/`
- Cấu hình DB: `elearning/config/config.php` (sao chép từ `config.php.sample`)
- Import CSDL: `elearning/sql/schema.sql` rồi `elearning/sql/seed.sql`

## 🚀 Hướng dẫn sử dụng code từ GitHub

### Bước 1: Clone repository

```bash
git clone https://github.com/dzduu562-tech/code-web.git
cd code-web
git checkout cursor/build-school-e-learning-website-c73d
```

### Bước 2: Copy vào XAMPP

```bash
# Windows
xcopy /E /I . C:\xampp\htdocs\elearning

# Linux/Mac
cp -r . /opt/lampp/htdocs/elearning
```

### Bước 3: Tạo Database

1. Start XAMPP (Apache + MySQL)
2. Truy cập `http://localhost/phpmyadmin`
3. Create database: `elearning_db`
4. Import `database/schema.sql`
5. Import `database/seed.sql`

### Bước 4: Cấu hình

Mở `config/config.php`:
```php
define('BASE_URL', 'http://localhost/elearning/public');
```

### Bước 5: Truy cập

```
http://localhost/elearning/public
```

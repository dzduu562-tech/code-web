╔══════════════════════════════════════════════════════════════╗
║     SAU KHI CLONE - IMPORT DATABASE                         ║
╚══════════════════════════════════════════════════════════════╝

1. Mở: http://localhost/phpmyadmin

2. Tạo database mới:
   - Tên: elearning_db
   - Collation: utf8mb4_unicode_ci
   - Click "Create"

3. Import schema:
   - Click vào database "elearning_db"
   - Tab "Import"
   - Choose file: C:\xampp\htdocs\elearning\database\schema.sql
   - Click "Import"
   - ✅ Thấy 22 bảng!

4. Import data:
   - Tab "Import" lại
   - Choose file: C:\xampp\htdocs\elearning\database\seed.sql
   - Click "Import"
   - ✅ Có 6 users!


╔══════════════════════════════════════════════════════════════╗
║     CẤU HÌNH APACHE (CHỈ LÀM 1 LẦN)                        ║
╚══════════════════════════════════════════════════════════════╝

1. Mở XAMPP Control Panel

2. Apache → Config → httpd.conf

3. Tìm dòng (Ctrl+F):
   #LoadModule rewrite_module modules/mod_rewrite.so

4. Xóa dấu #:
   LoadModule rewrite_module modules/mod_rewrite.so

5. Tìm dòng:
   <Directory "C:/xampp/htdocs">
       AllowOverride None

6. Đổi None → All:
   <Directory "C:/xampp/htdocs">
       AllowOverride All

7. Save file

8. Stop Apache → Start Apache
